Predictive Modeling of Stroke Risk

This project brought together exploratory data analysis, statistical modeling, feature engineering, and machine-learning classification to study stroke risk, with an interactive dashboard built to explore the work.

Workflow

The analysis covers exploratory data analysis, feature engineering, statistical modeling, and classification. Methods listed for the project include Random Forest and Gradient Boosting.

Tools

Python, scikit-learn, R Shiny, and biostatistics were used to develop the analysis and interactive dashboard.

This is an academic project and is not intended for diagnosis or medical decision-making.
